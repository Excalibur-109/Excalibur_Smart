PBR Demo：一条可切换三后端的渲染流水线

这个示例用一个 Win32 HWND 创建窗口，把 stb_image 解码的金属材质和天空盒上传到 RHI，再通过 RenderGraph 依次完成阴影、PBR、UI 和 Present。源码命名空间保持小写 rhi，便于和公共 RHI API 一致。

已验证Debug 构建可生成 PBRDemo，并已在 Vulkan、D3D11、D3D12 下运行退出码为 0。UI 贴图切换和旋转速度滑块在截图中可见。Vulkan 环境若出现第三方 Epic Overlay layer JSON 警告，属于外部 layer 配置，不是本 Demo 的 RenderGraph 错误。

1. 初始化顺序

WinMain / ParseOptions
  └─ PBRDemoApp::Run
       ├─ CreateWindowHandle       注册 WNDCLASSEXW，创建 HWND
       ├─ CreateDevice              选择 Vulkan / D3D11 / D3D12
       ├─ CreateStaticResources     网格、纹理、UBO、bind set、pipeline layout
       ├─ CreateSwapchainResources  swapchain、depth、依赖格式的 pipeline
       ├─ CreateUI                  创建 UI pipeline/context
       ├─ MainLoop                  acquire → BuildFrame → submit → present
       └─ Cleanup                   WaitIdle 后逆序销毁

Run 的顺序是资源依赖的可执行文档。窗口先存在，Vulkan 才能由回调创建 VkSurfaceKHR；swapchain 格式确定后才能创建颜色 attachment 兼容的 PBR/UI pipeline。窗口最小化时客户区为 0，程序暂缓创建和提交，避免把无效 extent 传给后端。

3. 场景资源

网格和顶点布局

MakeSphere(32, 64) 通过经纬线生成 UV sphere；每个顶点包含 position、normal、uv 和 tangent。MakePlane 生成 XZ 平面的地面。两个网格合并进一个 vertex/index buffer，通过 vertex offset 和 index offset 选择绘制范围。tangent.w 保存 handedness，PBR fragment shader 据此构建法线贴图的 TBN 基。

stb_image 与材质

LoadImageRGBA8 强制 STBI_rgb_alpha，把 PNG/JPG 解码为连续 RGBA8 CPU 数组，并检查尺寸、乘法溢出和加载失败原因。MaterialTextureSlot 有五个槽：

槽位文件示例格式shader 用途
BaseColormetal_18_basecolor-2K.pngRGBA8_SRGB反照率；采样时转线性空间。
Normalmetal_18_normal-2K.pngRGBA8_UNormTBN 中的切线空间法线。
Metallicmetal_18_metallic-2K.pngRGBA8_UNorm金属度，影响 F0 与漫反射。
Roughnessmetal_18_roughness-2K.pngRGBA8_UNorm微表面粗糙度，控制高光宽度。
Heightmetal_18_height-2K.pngRGBA8_UNorm视差/高度偏移参数。

五张图使用同一个 repeat + linear sampler。每张 texture 另建一个 2D view；图形绑定集把 view、texture 和 sampler 作为 combined texture/sampler 提供给 fragment shader。材质贴图在每帧上传列表中只保留首次上传需要的 CPU 数据，之后 GPU 资源可复用。

天空盒

sky 目录的 px/nx/py/ny/pz/nz 按 cubemap layer 顺序读取，检查六面都是相同正方形尺寸，然后创建 6-layer、CubeCompatible 的 RGBA8 sRGB texture 和 Cube view。天空盒 vertex shader 使用球体 position 作为方向，移除相机平移；fragment shader 用相机方向采样 cubemap。其 uniform binding 0 同时对 Vertex 和 Fragment 可见，因为像素阶段还读取 materialParameters.w 的天空旋转角。

4. UniformBufferObject 与相机

UniformBufferObject 用 alignas(16) 对齐，与 GLSL std140/HLSL cbuffer 对应：

字段内容使用阶段
model模型到世界矩阵顶点变换；球体带时间旋转。
view / projection相机观察和透视投影主 PBR、skybox。
lightDirection / lightColor方向光和颜色直接光照、shadow。
cameraPosition世界空间相机位置视线方向、反射向量。
baseColorbaseColor.rgb 与 metallic.a材质常量乘贴图。
materialParametersroughness、AO、height、skybox Y 旋转PBR/天空盒参数。
lightViewProjection / shadowParametersshadow map 坐标和 bias/texel sizeshadow depth compare + PCF。

Math 的矩阵是行主序，而 shader 接收 column-major 约定，因此 ToShaderMatrix 在上传前转置。Vulkan 和 D3D 的 viewport Y 方向不同：只对 Vulkan 的 projection[1][1] 翻转，避免两套后端同时翻转导致画面上下颠倒。

按住右键进入 mouse-look：窗口捕获光标，把相对移动转换为 yaw/pitch，并把 pitch 限制在约 ±1.5 弧度；释放右键恢复原来的屏幕光标位置。球体旋转使用单调时钟，sphereRotationDegreesPerSecond_ 由 UI slider 修改，最终在 MakeUniform(true) 中影响 model 矩阵。

5. RenderGraph 的四个 pass

ShadowMap  (depth clear/store)
      ↓ ShadowDepth: DepthWrite → ShaderRead
OpaquePBR  (backbuffer/depth clear/store)
      ↓ BackBuffer: ColorAttachment
UI         (backbuffer/depth load/store)
      ↓ BackBuffer: ColorAttachment → Present
Present
Pass读取写入/attachment关键原因
ShadowMapVertices、Indices、SphereUniformShadowDepth，Clear + Store从光源视角写入 D32 深度；后续 PBR 必须采样，所以不能 Discard。
OpaquePBR网格、UBO、ShadowDepth、Skybox、五张材质图BackBuffer 和 Depth，Clear + Store完成天空盒、地面、球体和直接光照/阴影。
UIUI.Vertices、UI.White、选中的外部材质图BackBuffer 和 Depth，Load + StoreLoad 保留 PBR 颜色；PSO 禁用深度测试/写入，仅做 alpha 合成。
PresentBackBuffer，Present 状态交换链呈现把颜色 attachment 状态转换到后端 present 所需状态。

BuildFrame 先把长期存活的 RHI 句柄以 imported resource 放入图，再添加 pass 描述和 workload。提交列表明确写成 ShadowMap、OpaquePBR、UI、Present，让图编译器验证依赖并插入后端所需 barrier；D3D11 虽没有显式 barrier，也需要按相同顺序解绑 DSV、绑定 SRV。

6. shader 与 CMake

RHI/PBRDemo/CMakeLists.txt 调用 glslangValidator -V 把 GLSL 编译成 pbr.vert.spv、pbr.frag.spv、skybox 和 shadow SPIR-V；UI 的 GLSL 也在这里编译。D3D11/12 运行时从复制到 build 目录的 HLSL 文件编译指定入口点。这样源代码只维护一份 HLSL，而 Vulkan 仍满足 shader module 必须使用合法 SPIR-V 字节码的要求。

shader 绑定约定在三后端保持一致：UBO 位于 b0/set binding 0，纹理和 sampler 使用固定寄存器/绑定号，顶点语义是 POSITION/NORMAL/TEXCOORD/TANGENT。Skybox 的 uniform binding 0 必须同时声明 Vertex + Fragment 可见，否则 D3D12 root signature/PSO 会拒绝像素 shader 读取该 cbuffer。

7. UI 交互与运行

左侧面板提供五个按钮：Base Color、Normal、Metallic、Roughness、Height。按钮只改变 selectedMaterialTexture_，右侧 Image 预览对应的 RHI texture/view；PBR 绑定仍使用同一套五纹理，故切换不会重建 pipeline。滑块把球体速度从 0 到 180 DEG/S 量化为 1 度，下一帧的 model 矩阵立即反映新值。

cmake --build build/PBRDemo --config Debug --target PBRDemo --parallel 4
build\PBRDemo\Debug\PBRDemo.exe --api=vulkan
build\PBRDemo\Debug\PBRDemo.exe --api=d3d11
build\PBRDemo\Debug\PBRDemo.exe --api=d3d12

截图验证文件位于 build/PBRDemo/pbr-ui-vulkan.png、pbr-ui-d3d11.png、pbr-ui-d3d12.png 和 pbr-ui-normal-slider.png。最后一张包含 Normal 贴图切换以及约 138 DEG/S 的旋转速度显示。
