RenderGraph：把声明编译成执行计划

RenderGraph 的输入不是原生命令，而是一张“哪个 pass 读/写哪个资源”的声明图。编译器利用这些信息得到稳定的执行顺序、资源状态转换、生命周期和瞬态别名分配。

核心收益调用方不必手工维护“上一 pass 把 texture 写成 RenderTarget，这一 pass 需要 ShaderRead”的全局状态机。只要正确声明 reads/writes，编译计划会形成后端可翻译的 transition。

输入：资源、pass、workload

描述关键内容它表达什么
RHIRenderGraphBufferDescname、RHIBufferDesc、flags、imported、externalHandle内部创建或外部导入的 buffer。
RHIRenderGraphTextureDescname、RHITextureDesc、flags、imported、externalHandle内部创建或外部导入的 texture；swapchain image 通常属于导入资源。
RHIRenderGraphResourceRefname、type、state、stages、access一个 pass 如何读写某个逻辑资源。
RHIRenderGraphPassDesctype、queue、dependsOnPasses、reads、writes、attachments、async/cull/side effect 标记pass 的依赖和访问意图。
RHIRenderPassWorkloadpassName、draw/dispatch/copy/查询/间接命令等与 passName 对应的具体工作内容；编译时验证其是否适合 pass type。

编译流程

1. 验证。检查资源名、pass 名、读写引用、attachment、workload 与 pass 类型是否匹配。
2. 建依赖。从显式 dependsOnPasses 以及资源 hazard（读后写、写后读、写后写）构建边。
3. 裁剪。从 Exported、NeverCull、有副作用或最终可见输出反向标记。没有可观察结果的 cullable pass 将被排除。
4. 拓扑排序。生成 live pass 的稳定顺序；若出现环，编译失败。
5. 追踪状态。按排序观察每个资源的 state、stage、access、queue；差异产生 RHIRenderGraphTransition。
6. 分配瞬态槽。对 Transient 且 AllowAliasing 的兼容资源，根据不重叠生命周期复用 allocation slot。
7. 输出计划。后端拿到 RHIRenderGraphExecutionPlan，把 transition 和 workload 录制为原生命令。

输出：RHIRenderGraphExecutionPlan

字段作用后端使用方式
structureHash图结构与 workload 结构的哈希可用于缓存静态调度；动态 clear value/viewport 不必使结构缓存失效。

       v

在 Vulkan，transition 会成为 image layout/access/stage barrier；在 D3D12，主要成为 D3D12_RESOURCE_BARRIER；在 D3D11，它更多是逻辑正确性与绑定顺序的约束，因为 API 没有显式 resource layout。

提交验证不是额外的调度器

ValidateRHIRenderGraphSubmissions 验证调用方手写的 RHIQueueSubmitDesc 是否遵循已编译的依赖。它不会替代 graph 计划：计划决定 pass 顺序和 barrier；submission 描述的是队列 wait/signal 的外部同步意图。提交列表为空时，后端可以使用默认提交路径。

别名的含义编译器已经计算 alias allocation slot，但“两个逻辑资源共用同一块 native memory”的细节由 frame 后端负责。把一个资源标为 AllowAliasing 前，必须保证生命周期不重叠、格式/尺寸/usage 兼容，且不会在图外继续使用。

学习检查

  1. 给每个跨 pass 资源写出唯一名字，并在 reads/writes 中写出准确 state。
  2. 区分 Imported（图不拥有）、Exported（图后还要用）、Transient（短命）与 NeverCull（有外部副作用）。
  3. 将图结构变化和每帧动态参数变化分开；前者影响 hash/计划缓存，后者通常不应影响。
  4. 先让 graph 自动生成 transition；不要在当前 frame 路径中填写 workload 显式 barrier。
