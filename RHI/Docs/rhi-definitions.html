RHI/RHIDefinitions.hpp

资源、枚举与描述符

RHIDefinitions.hpp 是整个 RHI 的词典。上层只表达“我要什么资源、怎样访问、在哪个阶段使用”，后端再分别生成 Vk/D3D11/D3D12 对象和命令。

设计原则把 API 特有的指针和枚举隔离在后端。比如 RHIBufferDesc 能变成 VkBuffer、ID3D11Buffer 或 ID3D12Resource，但上层不依赖其中任一个头文件。

1. 逻辑句柄：所有资源的共同入口

RHIHandle<Tag> 保存一个 u64 value。值 0 无效，后端使用从 1 开始的索引访问自己 Impl 中的资源 vector。不同 Tag 让 C++ 在编译期阻止把纹理误传给 buffer 接口。

句柄代表的逻辑对象典型原生映射
RHIBuffer顶点、索引、uniform、storage、staging 数据VkBuffer / ID3D11Buffer / ID3D12Resource
RHITexture纹理、RT、深度图、swapchain image 的存储VkImage / ID3D11Texture* / ID3D12Resource
RHITextureView对纹理指定 mip/layer/aspect/格式的访问方式VkImageView / SRV-RTV-DSV-UAV
RHISampler采样过滤、寻址、比较规则VkSampler / ID3D11SamplerState / D3D12 sampler descriptor
RHIShader着色器模块或已编译字节码VkShaderModule / D3D11 shader COM object / bytecode
RHIBindSetLayout、RHIBindSet资源槽位形状与实际资源填写descriptor set layout/set；D3D descriptor table 语义
RHIPipelineLayout、RHIPipeline绑定接口与 graphics/compute 状态组合VkPipelineLayout/Pipeline；D3D12 RootSignature/PSO；D3D11 状态组合
RHISwapchain、RHIQueryPool、信号句柄呈现、查询、GPU-GPU / CPU-GPU 同步各 API 对应的 swapchain、query、semaphore/fence 模型

11. RenderGraph 描述层

RHIRenderGraphResourceType 为 Buffer、Texture、SwapchainImage；RHIRenderGraphResourceFlags 为 None、Imported、Exported、Transient、AllowAliasing、NeverCull；RHIRenderGraphPassType 为 Raster、Compute、Copy、Present。

每个 RHIRenderGraphPassDesc 提供显式依赖、reads、writes、color/depth attachments、期望 queue、是否允许 async compute、是否可裁剪以及是否有副作用。详细编译行为见 RenderGraph 页。
